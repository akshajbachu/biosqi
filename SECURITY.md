# Security Policy

## Supported versions

Security fixes are applied to the latest released version of biosqi.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/akshajbachu/biosqi/security/advisories/new).
Include a description of the issue, steps to reproduce it, and the affected
version. You can expect an initial response within seven days.

## Scope

biosqi processes recordings locally. The `biosqi view` dashboard binds to
`127.0.0.1` by default and is not designed to be exposed to untrusted networks.
biosqi is research software, not a medical device.
